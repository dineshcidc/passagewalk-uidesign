## Design

- Background: client green gradient (`#45682a` → `#1b2a10`), gold accent `#f3c96f`, cream text `#fbf8ef`.
- Fonts: Newsreader Italic 500 (captions), DM Sans 700 (eyebrows), the same as the app.
- A gold dotted "walking path" runs across all 8 images, so the set reads as one walk when swiped in the store.
- Some slides lift one card out of the screen (progress card, step ring, passage card, verse, certificate, calendar week).
- Flat look, no shadows anywhere (user preference): no phone / card / text shadows in the design, and the app screens were captured with UI shadows turned off.
- Real app UI only (Apple 2.3.3). Sample user name "Sarah". No price / "#1" / "Free" / "Download now" wording.
